# Random Password Generator

# Description

A beginner-friendly Python command-line tool that generates strong random passwords based on user-defined criteria.

The user can choose the password length and select the types of characters to include.

# Features

* Minimum password length of 8 characters
* Supports uppercase letters
* Supports lowercase letters
* Supports numbers
* Supports symbols
* At least two character types must be selected
* Validates user input
* Generates random passwords
* Allows the user to generate multiple passwords without restarting the program

# Technologies Used

* Python
* random module
* string module

# How to Run

1. Make sure Python is installed on your computer.
2. Open the project folder in the terminal.
3. Run the following command:

bash
python3 Randompasswordgenerator.py


# How to Use

1. Enter the desired password length.
2. The minimum length is 8 characters.
3. Select at least two character types:

   * 1 — Uppercase letters
   * 2 — Lowercase letters
   * 3 — Numbers
   * 4 — Symbols
4. The program generates a random password.
5. Choose whether you want to generate another password.

# Example

Enter password length (minimum 8): 12

Choose character types:
1. Uppercase letters (A-Z)
2. Lowercase letters (a-z)
3. Numbers (0-9)
4. Symbols (!@#$...)

Enter choices (example: 123): 1234

Generated Password: Example123!
